Экран настройки облика темы XI Novels: цвет, форма, шрифты и читалка — с живым предпросмотром сайта.

== Description ==

Студия — пульт для темы XI Novels. Слева ручки, справа настоящий сайт в рамке: каждое движение ползунка видно сразу, без сохранения и перезагрузки.

* **Цвет** — акцент, цвет премиума, оттенок и насыщенность нейтральных. Фон, рамки и текст строятся из одного тона, поэтому палитра остаётся согласованной.
* **Форма** — скругление, тени, ширина сайта.
* **Шрифты** — системные стеки для интерфейса и для чтения. Ничего не грузится со стороны.
* **Читалка** — кегль, ширина колонки, интерлиньяж и бумага, с которых начинает новый читатель.
* **Наборы** — пять готовых обликов: графит, бумага, чернила, неон, газета.
* **Предпросмотр** — главная, каталог, страница тайтла и глава; монитор, планшет и телефон; светлая и тёмная схемы.
* **Перенос** — настройки выгружаются и загружаются файлом JSON.

Значения хранятся в обычных `theme_mod` темы. Выключите плагин — сайт останется таким же, просто ручки уедут в кастомайзер.

CSS предпросмотра собирает сама тема (`xin_skin_css()`), а не копия генератора в JavaScript, поэтому картинка в рамке не может разойтись с тем, что увидит читатель.

== Installation ==

1. Активируйте тему **XI Novels** — без неё студии нечего настраивать.
2. Загрузите `xi-studio.zip` в **Плагины → Добавить новый → Загрузить плагин** и включите.
3. Откройте **Студия темы** в меню админки.

== Frequently Asked Questions ==

= Плагин нужен, чтобы менять цвета? =

Нет. Те же настройки лежат в кастомайзере, в разделах «XI Novels: бренд и цвета» и «XI Novels: облик». Студия — это удобный экран с живым предпросмотром, а не отдельное хранилище.

= Что будет, если плагин удалить? =

Ничего: настройки остаются в теме. Экран студии просто исчезнет из меню.

= Кто может открыть студию? =

Пользователь с правом `edit_theme_options` — обычно администратор.
