# XIN Setup 3

Готовый модуль подготовки WordPress для XIN-V2 и XIN-Com. Установите папку `xin-setup` в `wp-content/plugins` и активируйте после темы. Дополнительные параметры находятся в **Инструменты → Настройка темы**.

После активации, смены темы и завершения импорта модуль запускает настройку при следующем посещении админки администратором. Поддерживаются стандартный WordPress Importer, XI Novel Import и XI From Fictioneer.

Автоматически настраиваются:

- ЧПУ `/%postname%/` и правила маршрутов `/novels/`, `/updates/`, `/read/…`.
- Главная, блог, библиотека, студия, вход, рейтинг и служебные страницы с правильными шаблонами.
- Недостающие меню, стандартные жанры и статусы, параметры чтения и миниатюр.
- Чтение по одной главе, комментарии для новых записей, вложенность обсуждений.
- Счётчики опубликованных глав и даты обновлений: по 100 тайтлов за запрос, продолжение через защищённый AJAX, пока открыта админка.

Повторный запуск не создаёт дубликаты страниц, не переписывает тексты существующих страниц и не заменяет назначенные меню. Исходные параметры сохраняются в `xs_setup_snapshot`, результат — в `xs_setup_report`. Модуль не создаёт пользователей и пароли, не открывает ранее закрытые обсуждения и не меняет регистрацию.

Неоднозначные исправления старого импорта (главы без тайтла, номера, отсутствующие обложки) остаются отдельными действиями на экране диагностики. Перед большим импортом сделайте резервную копию базы и `uploads`.

WordPress обновляет Apache rewrite через `.htaccess`, если файл доступен для записи. Для Nginx администратор сервера должен настроить fallback:

```nginx
try_files $uri $uri/ /index.php?$args;
```

Плагин не может изменить конфигурацию Nginx или восстановить отсутствующие файлы изображений. Если включаете плагин раньше темы, после активации XIN-V2 откройте админку или нажмите кнопку автоматической настройки.
