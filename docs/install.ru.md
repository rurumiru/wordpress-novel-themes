# Установка

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| WordPress | 6.4 | 6.6+ (проверено до 7.0) |
| PHP | 7.4 | 8.1–8.3 |
| База | MySQL 5.7 / MariaDB 10.3 | MySQL 8 / MariaDB 10.6 |
| Расширения PHP | `gd` (обложки), `mbstring` | `imagick` для более чётких миниатюр |

Ни composer, ни node, ни задач по крону, ни внешних сервисов.

## 1. Поставить тему

**Из репозитория**

```bash
git clone https://github.com/rurumiru/wordpress-novel-themes.git
cp -r wordpress-novel-themes/themes/xi-novels /путь/к/wordpress/wp-content/themes/
```

**Архивом** — скачайте репозиторий, упакуйте папку `themes/xi-novels` в zip и загрузите через *Внешний вид → Темы → Добавить новую → Загрузить тему*.

Активируйте в **Внешний вид → Темы → XI Novels**.

## 2. Что делает активация

* создаёт страницы **Кабинет автора** (`/dashboard/`) и **Моя библиотека** (`/library/`) с нужными шаблонами;
* заводит статусы выпуска: Выходит, Завершён, Заморожен, Анонс;
* регистрирует типы записей `novel` и `chapter` и таксономии `genre`, `novel_tag`, `novel_status`;
* пересобирает постоянные ссылки.

## 3. Что проверить в настройках

| Где | Что |
|---|---|
| Настройки → Постоянные ссылки | **Название записи**. Тайтлы живут по `/novels/<слаг>/`, главы — по `/read/<слаг>/` |
| Настройки → Чтение | «Ваши последние записи» подходит — тема сама рисует главную. Если хотите статическую главную, задайте её и укажите «Страницу записей» для блога |
| Настройки → Обсуждение | Делать нечего: комментарии отключены темой везде |
| Внешний вид → Меню | Создайте меню и назначьте на **Главное меню** (по желанию — «Меню подвала», «Правовые ссылки») |
| Внешний вид → Настроить | Акценты, схема по умолчанию, блоки главной, текст подвала, соцсети |

## 4. Первый тайтл

1. **Новеллы → Добавить.** Название, краткое описание (цитата) и полное описание — то, что видит читатель.
2. Поставьте **обложку** изображением записи, лучше в пропорции 2:3 (800×1200).
3. По желанию — **широкий арт** в боковом блоке: он идёт в баннер главной и крупные секции (1920×720).
4. Выберите **жанры**, **теги** и **статус выпуска**.
5. **Главы → Добавить**, выберите новеллу, задайте номер, опубликуйте.

Либо всё то же самое с фронта: **Кабинет автора** → *Новый проект* → *Добавить главу*. См. [authoring.ru.md](authoring.ru.md).

## 5. Превью без MySQL (песочница)

Пригодится, чтобы посмотреть тему или разрабатывать на ноутбуке.

```bash
# 1. копия WordPress
curl -O https://wordpress.org/latest.zip && unzip latest.zip

# 2. официальный SQLite-дропин
curl -L -o sqlite.zip https://downloads.wordpress.org/plugin/sqlite-database-integration.zip
unzip sqlite.zip -d wordpress/wp-content/plugins/
cp wordpress/wp-content/plugins/sqlite-database-integration/db.copy wordpress/wp-content/db.php
# в db.php заменить {SQLITE_IMPLEMENTATION_FOLDER_PATH} на sqlite-database-integration
# и {SQLITE_PLUGIN} на sqlite-database-integration/load.php

# 3. тема
cp -r themes/xi-novels wordpress/wp-content/themes/

# 4. wp-config.php с любыми DB_* (SQLite их игнорирует) и
#    define( 'WP_HOME', 'http://localhost:8080' );
#    define( 'WP_SITEURL', 'http://localhost:8080' );

# 5. запуск
php -S localhost:8080 -t wordpress tools/dev-router.php
```

Откройте `http://localhost:8080`, пройдите пятиминутную установку, активируйте тему.

`tools/dev-router.php` нужен только потому, что встроенный сервер PHP не умеет ЧПУ; Apache, nginx и LiteSpeed ничего дополнительного не требуют.

## 6. Заметки для продакшена

* **Кеш.** Любой страничный кеш подходит. Просмотры считаются с защитой кукой, поэтому кешированная страница не ломает счётчик.
* **Картинки.** Тема регистрирует размеры `xin-cover` (320×480), `xin-cover-lg` (520×780), `xin-cover-sm` (120×180), `xin-banner` (1920×640) и `xin-wide` (720×405). После импорта чужой медиатеки перегенерируйте миниатюры.
* **Спрятать WordPress глубже.** Тема уже убирает generator, RSD/wlwmanifest, oEmbed, emoji, X-Pingback, версии в путях и переносит REST на `/api/`. Чтобы убрать ещё и `/wp-content/` из адресов, добавьте в `wp-config.php`:

  ```php
  define( 'WP_CONTENT_DIR', dirname( __FILE__ ) . '/assets' );
  define( 'WP_CONTENT_URL', 'https://example.com/assets' );
  ```

  и переименуйте папку.
* **Загрузки.** Главы — это текст, а обложки нет: держите `upload_max_filesize` от 8M, чтобы автор мог приложить арт прямо из кабинета.

## Если что-то не так

| Симптом | Решение |
|---|---|
| Главы отдают 404 | Пересохраните постоянные ссылки (Настройки → Постоянные ссылки) |
| Кабинет пишет «Недостаточно прав» | Нужна роль не ниже «Автор»; «Участник» отправляет на модерацию |
| Обложки растянуты | Используйте 2:3 и перегенерируйте миниатюры |
| В кабинете нет визуального редактора | В профиле пользователя выключен визуальный режим либо браузер не распознан движком |
| На главной пустое состояние | В каталоге ещё нет опубликованных тайтлов |
