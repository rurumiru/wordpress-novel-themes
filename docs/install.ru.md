# Установка XIN-V2 3

Основная тема — `themes/xin-v2`. XIN-Com сохранена как альтернативная. Требуются WordPress 6.4+, PHP 8.0+, `mbstring`, обработка изображений и `ZipArchive` для EPUB.

1. Перед обновлением сохраните копию базы и `uploads`.
2. Скопируйте `themes/xin-v2` в `wp-content/themes`, активируйте **XI Community Library**.
3. Скопируйте `plugins/xin-setup` в `wp-content/plugins`, активируйте и откройте админку.
4. Импортируйте новеллы, главы и обложки. После поддерживаемого импорта модуль запланирует повторную настройку.
5. Проверьте отчёт в **Инструменты → Настройка темы**. Там же доступны отдельные исправления старого импорта.

Автонастройка создаёт недостающие страницы, привязывает шаблоны, назначает отсутствующие меню, задаёт ЧПУ `/%postname%/`, обновляет маршруты, жанры, миниатюры и счётчики. Тексты существующих страниц и назначенные меню сохраняются. Большие пересчёты продолжаются через защищённый AJAX, пока открыта админка.

На Apache нужен работающий rewrite и доступный для записи `.htaccess`. Для Nginx настройте fallback в серверном блоке:

```nginx
try_files $uri $uri/ /index.php?$args;
```

Репозиторий содержит исходники и демонстрационные иллюстрации, а не установленный WordPress или базу. Тестовые аккаунты на продакшене не создаются. Ссылка dev-входа показывается только на локальном PHP dev-сервере с localhost и использует обычную авторизацию WordPress.

Каталог, чтение, обсуждения и студия встроены в тему. Дополнительные плагины импорта и управления подключаются по необходимости. Фронтенд не требует сборки; шрифты и ресурсы локальные. Gravatar, внешние ссылки «поделиться», web push и сторонние интеграции имеют отдельные сетевые требования.
