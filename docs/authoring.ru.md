# Руководство автора

Всё, что нужно автору или переводчику, без захода в `/wp-admin`.

## Роли

| Роль | Что может |
|---|---|
| **Автор** | Создавать проекты и сразу публиковать главы |
| **Участник** | Создавать проекты и главы; они уходят в «На утверждении» |
| **Редактор / Администратор** | Всё, включая чужие проекты |

Новому переводчику выдайте роль «Автор» в **Пользователи → Добавить**.

## Кабинет

Откройте `/dashboard/` (в шапке — *Кабинет*, либо меню профиля). Четыре экрана:

* **Мои проекты** — все ваши проекты с числом глав, просмотрами и статусом.
* **Новый проект / Правка проекта** — карточка тайтла.
* **Главы** — таблица глав одного проекта.
* **Новая глава / Правка главы** — экран письма.

## Создание проекта

| Поле | Комментарий |
|---|---|
| **Название** | Видно везде; из него получается слаг URL |
| **Автор оригинала** | Свободный текст — для переводов автор первоисточника |
| **Оригинальное название** | По желанию, показывается под заголовком |
| **Перевод / команда** | Строка в сайдбаре тайтла |
| **Год выпуска** | По желанию |
| **Краткое описание** | Одна-две фразы для карточек каталога, поиска и витрины |
| **Полное описание** | Визуальный редактор; идёт под заголовком «Описание», сворачивается после ~220px |
| **Жанры** | Несколько; питают чипы каталога и блок «Похожее» |
| **Статус выпуска** | Выходит / Завершён / Заморожен / Анонс |
| **Теги** | Через запятую, создаются на лету |
| **Обложка (2:3)** | 800×1200 или больше; используется везде |
| **Широкий арт** | 1920×720; идёт в баннер главной, тренд-блок и размытую подложку страницы тайтла |
| **Материал 18+** | Размывает обложку в списках и ставит бейдж |

Кнопки: *Сохранить и опубликовать*, *В черновики*, *Удалить* (в корзину).

## Написание главы

* **Название главы** — свободный текст. «Глава 12» подставляется из номера, поэтому в названии нужно только имя.
* **Номер** — уже подставлен следующий. Дробные номера (`12.5`) — для экстр и интерлюдий; читалка показывает их как `#12.5` и держит порядок.
* **Текст** — визуальный редактор WordPress. Вставляйте из Word или Google Docs; вкладка *Код* — для ручного HTML. Кнопка *Добавить медиа* грузит иллюстрации в главу.
* **Ранний доступ (PLUS)** — глава видна в оглавлении с замком и читается только вошедшими.

Три кнопки: *Опубликовать*, *Опубликовать и начать следующую* (удобно, когда выкладываете пачку), *В черновики*.

Пока вы печатаете, текст автосохраняется в браузере. Если вкладка закрылась — откройте экран снова, черновик подставится в пустой редактор (уже сохранённую на сервере версию он не затирает). Счётчик слов под полем обновляется на лету.

## Выкладка пачкой

1. *Новый проект*, заполнить карточку, опубликовать.
2. *Добавить главу* → написать → **Опубликовать и начать следующую**.
3. Повторять. Номер увеличивается сам.

Публикация главы обновляет и сам тайтл, поэтому он поднимается в «Недавно обновлены» и в ленту обновлений.

## Что видит читатель

* В списке глав на странице тайтла есть поиск и переключатель порядка.
* Читалка помнит для каждого посетителя кегль, интерлиньяж, ширину колонки, шрифт и «бумагу».
* Прогресс чтения хранится в браузере и выносится на главную в блок «Продолжить чтение».
* Оценки анонимные: один голос с браузера, усредняется в оценку тайтла.

## Перенос существующего сайта

Отдельного импортёра нет, но модель данных нарочно простая:

* тайтл — запись типа `novel`: обложка в изображении записи, синопсис в цитате;
* глава — запись типа `chapter` с двумя мета-полями: `_xin_novel` (ID тайтла) и `_xin_number` (число);
* дополнительно: `_xin_locked`, `_xin_adult`, `_xin_featured`, `_xin_views`, `_xin_rating`, `_xin_rating_count`, `_xin_background`, `_xin_author_name`, `_xin_original_title`, `_xin_translator`, `_xin_year`, `_xin_source`.

Подойдёт что угодно, умеющее создавать записи: WP All Import, скрипт на WP-CLI или тридцать строк PHP на `wp_insert_post()`.

```php
$novel_id = wp_insert_post( array(
	'post_type'    => 'novel',
	'post_status'  => 'publish',
	'post_title'   => 'Название тайтла',
	'post_excerpt' => 'Краткое описание в одну строку',
) );

$chapter_id = wp_insert_post( array(
	'post_type'    => 'chapter',
	'post_status'  => 'publish',
	'post_title'   => 'Первый шаг',
	'post_content' => $html,
) );
update_post_meta( $chapter_id, '_xin_novel', $novel_id );
update_post_meta( $chapter_id, '_xin_number', 1 );
```
