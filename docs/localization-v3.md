# Interface localization — 3.0.3

The theme ships English (`en_US`) and Brazilian Portuguese (`pt_BR`) interface translations. The compiled catalogs contain 683 entries each, with no missing extracted source strings and no Cyrillic translation values.

Reviewed changes include ranking labels and descriptions, natural Brazilian Portuguese wording for ratings and author access, standard navigation/page labels, genre and release-status names, local development login messages, comment reply controls and the live studio word counter. English and Portuguese count labels now use the singular only for one, rather than the Russian 21/101 rule.

WordPress menu labels and standard taxonomy labels are translated at rendering time. Stored content and slugs are preserved. Novel names, author names, synopsis text, chapter text, blog articles and custom user-defined labels remain author content; choosing an interface language does not translate these documents automatically.

Browser verification covered rating and update sorts, a Fantasy filter, English controls, Brazilian Portuguese controls and 320/390-pixel layouts. The checked ranking headings, controls, column labels, explanatory text and footer columns contained no Cyrillic UI text in PT-BR. JavaScript console checks reported no errors.
