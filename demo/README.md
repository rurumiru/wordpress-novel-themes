# XI Novels — демо-импорт 3.0.1

Установите ZIP как **плагин**: Плагины → Добавить → Загрузить плагин. Активируйте тему XIN-V2, затем откройте **Инструменты → Демо-контент → Установить демо-контент**.

Пакет содержит 15 тайтлов, 65 глав с оригинальными демонстрационными текстами, жанры и теги, 5 записей блога и 3 баннера. Три тайтла — «Сад ржавых механизмов», «Тихий этаж», «Клинок и бумажный фонарь» — получают готовые иллюстрированные обложки и широкие арты. Остальные получают абстрактные обложки без встроенных букв. Готовые иллюстрации созданы через встроенный ImageGen для этого проекта; во время импорта генерация и сетевые загрузки не нужны. Для создания миниатюр и остальных изображений требуется PHP GD.

Оценки, просмотры, имена авторов и тексты — демонстрационные данные. Последние главы отмечены как ранний доступ для проверки оформления закрытых глав.

Повторный импорт обновляет только записи с меткой `_xin_demo`. Существующий собственный тайтл, статья или баннер с тем же адресом пропускается. Импорт не создаёт пользователей и не меняет пароли. После него модуль XIN Setup получает сигнал обновить настройку сайта и счётчики.

Демо можно убрать на той же странице; выбирайте перенос в корзину, если нужна возможность восстановления. Перед импортом на рабочий сайт сохраните резервную копию.
