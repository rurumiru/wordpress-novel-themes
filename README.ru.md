## Версия 2 — что изменилось

В репозитории теперь **две темы**, и они делят одну базу данных: перейти с одной на другую
можно переключателем в админке, ничего не перенося.

| | |
|:--|:--|
| **XIN-V2** — новая | Тёплая бумага, антиква в заголовках, волосяные линии вместо теней. Читалка с бесконечной прокруткой и озвучкой, библиотека читателя, уголок сообщества, вход прямо на сайте. Написана с нуля под большие библиотеки. |
| **XIN-Com** — классическая | Та же платформа в плотной, «журнальной» подаче. Раздел комиксов, баннеры, панель управления, рейтинги по периодам. Остаётся в репозитории и продолжает получать правки. |

Появились **два новых плагина**: `XIN Turbo` разгоняет любой WordPress, `XIN Setup` за один
экран приводит сайт и уже накопленные записи в состояние, с которым тема работает как задумано.

Полный список правок — в [CHANGELOG.md](CHANGELOG.md).

## Почему это

Громкое заявление стоит ровно столько, сколько под ним измерений и кода. Вот они.

| | |
|:--|:--|
| 📚 **Всё в теме, а не в пяти плагинах** | Каталог, главы, читалка, рейтинги, оценки, библиотека, кабинет автора, выгрузка книг, обсуждения, словарь проекта, уведомления — одна кодовая база, одна модель данных, один набор настроек. |
| 🚀 **Держит большие библиотеки** | Порядок глав живёт отдельным индексом в мете тайтла. Оглавление на тайтле в четыре тысячи глав стоит **6 запросов**, переход «следующая глава» — тоже 6, каталог из 24 карточек со всей метой и обложками — **9**. Без прогрева кэша те же 24 карточки дают 91 запрос. |
| 📖 **Читалка, в которую возвращаются** | Бесконечная прокрутка: дочитали главу — следующая дописывается сама, адрес в строке браузера меняется на неё. Размер, ширина, бумага, тема; закладки и цитаты по абзацам; подсказки словаря; чтение вслух; полоса прогресса. |
| 🔌 **Ни одного внешнего запроса** | Ни CDN, ни Google Fonts, ни счётчиков. Четыре гарнитуры лежат в теме — 22 файла, только кириллица и латиница. Страница целиком грузится с вашего домена. |
| 🛠 **Ни одного шага сборки** | Ни npm, ни composer, ни компиляции. Скачали, распаковали в `wp-content/themes`, включили. |
| ✍️ **Автор публикует с сайта** | Кабинет, редактор главы, расписание выхода, ранний доступ, соавторы, словарь проекта — не открывая `/wp-admin`. |
| 🌍 **Три языка из коробки** | 601 строка в теме: русский исходник, собранные `en_US` и `pt_BR`, переключатель RU / EN / PT в шапке. |
| 🔍 **Исходник, который можно читать** | ~13 000 строк PHP с комментариями о том, *почему так*, а не *что делает строка*. Ни одного обфусцированного JSON от конструктора страниц. |

> [!TIP]
> **Живая демонстрация — [xi.community](https://xi.community).** Настоящий сайт на этой теме:
> каталог, страница тайтла, читалка и её настройки.

| | |
|:--|:--|
| **Бесконечная прокрутка** | Следующая глава дописывается за два экрана до конца текущей. Адрес в строке браузера меняется на ту главу, что перед глазами: вкладка закрывается там, где читали, и открывается там же. |
| **Настройки чтения** | Восемь размеров шрифта, четыре ширины колонки, обычная и сепия, светлая и тёмная тема, режим без оглавления. Всё живёт в браузере читателя и переживает переход к следующей главе. |
| **Закладки и цитаты** | По клику на абзац. Закладка помечает место полосой на поле, цитата копируется вместе со ссылкой прямо на этот абзац. |
| **Словарь проекта** | Имена, титулы и названия техник подчёркиваются пунктиром, пояснение всплывает по наведению и по фокусу с клавиатуры. Один термин — один раз на абзац. |
| **Чтение вслух** | Штатный синтез речи браузера, по абзацу, с подсветкой читаемого. Начинает с того абзаца, который виден, а не с начала главы. |
| **Оглавление окном** | На тайтле в тысячи глав в разметку попадает сотня вокруг текущей, остальное догружается кнопками «выше» и «ниже». |
| **Клавиши** | Стрелки листают главы, `+` и `−` меняют размер, `Esc` закрывает кнопки абзаца. |

</details>

<details>
<summary><b>Ранний доступ, оплата и команда проекта</b></summary>

<br>

Закрытая глава понимает два замка сразу:

* **дата** — `_xin_unlock_at`: глава открывается всем в назначенный момент, а до него видна автору,
  редакторам и команде проекта;
* **покупка** — `_xin_product`: товар WooCommerce. Ключ общий с XIN-Com, поэтому глава, купленная
  там, открывается и здесь.

Проверка одна на всё: страница главы, оглавление, бесконечная прокрутка и выгрузка книги
отвечают одинаково. Закрытая глава не попадает ни в EPUB, ни в FB2.

Команда проекта — `_xin_team` на тайтле. Соавтор правит тайтл и его главы и читает ранний
доступ; состав меняет только владелец тайтла и редакторы.

</details>

## Скорость

Числа сняты на этом репозитории, на холодном кэше объектов. Повторить: `SAVEQUERIES` и счётчик
запросов вокруг вызова.

| Что | Запросов | Время |
|:--|--:|--:|
| Каталог, 24 карточки со всей метой и обложками | **9** | 11.6 мс |
| Оглавление, окно из 100 глав | **6** | 6.1 мс |
| Переход «предыдущая / следующая» | **6** | 3.8 мс |
| Страница тайтла целиком | 15 | 11.3 мс |
| Сводка витрины | 10 | 8.4 мс |

Те же 24 карточки без прогрева кэша меты — **91 запрос**. Разница в том, что тема поднимает мету,
термины и обложки всего списка одним запросом вместо запроса на карточку.

Порядок глав не собирается запросом на каждой странице: он лежит массивом идентификаторов в мете
тайтла и пересобирается сам, когда глава появляется, меняет номер, статус или исчезает. Поэтому
оглавление тайтла на четыре тысячи глав стоит столько же, сколько на четырёх.

Счётчик просмотров не пишет строку в базу на каждого посетителя: просмотры копятся в кэше объектов
и ложатся одним `UPDATE` на пачку. Прибавление идёт в самой базе — два посетителя в одну секунду
считаются как два, а не как один.

С плагином `XIN Turbo` страница для гостя отдаётся мимо WordPress:

| | Без кэша | С кэшем |
|:--|--:|--:|
| Страница тайтла | 0.41 с | **0.015 с** |
| Повторный заход с ETag | — | **304, 0 байт** |

## Установка

**Тема.**

1. Скачайте `xin-v2` из [релизов](../../releases) или скопируйте папку `themes/xin-v2`
   в `wp-content/themes`.
2. Включите её: **Внешний вид → Темы**.
3. Включите `XIN-V2 Kit` из `plugins/xin-v2-kit` — он держит типы записей вне темы.
4. Включите `XIN Setup` и откройте **Инструменты → Настройка темы**. Он покажет, чего не хватает,
   и заведёт страницы разделов, меню и настройки.

Всё. Ни сборки, ни зависимостей.

**Переезд с XIN-Com.** Переключите тему — данные останутся на месте: модель `_xin_*` у тем общая.
Страницы разделов у XIN-Com названы иначе, поэтому после переключения зайдите в
**Инструменты → Настройка темы**: он заведёт недостающие и не тронет существующие.

**Кэш страниц.** Включается отдельно, в **Настройки → Скорость** → «Установить перехватчик».
Плагин положит `wp-content/advanced-cache.php` и включит `WP_CACHE` в `wp-config.php`; при
выключении уберёт обратно.

## Языки

Интерфейс собран на трёх языках: русский — исходник, `en_US` и `pt_BR` — собранные файлы.
Переключатель RU / EN / PT стоит в шапке; выбор живёт в куке, поэтому ссылками делятся обычными.

Пересобрать после правки строк:

```
php tools/build-translations.php
```

Сборщик берёт строки прямо из исходников, сверяет их с картами в `tools/i18n/`, сообщает, чего
не хватает и что больше не используется, и пишет `.po` и `.mo` без `msgfmt`. Пропущенная строка
даёт ненулевой код возврата — значит, это ещё и проверка.

## Участие

Правки принимаются. Перед тем как отправлять:

* код на русском комментируется по-русски, строки интерфейса идут через `__()` с доменом темы;
* комментарий объясняет, **почему** так сделано, а не что делает строка;
* после правки строк — `php tools/build-translations.php`, он же проверка;
* новый файл темы подключается в `functions.php` рядом с остальными.
